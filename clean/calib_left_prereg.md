# LunarLeft 定向校准：事先约定（写于调用 API 之前，2026-10-27）

## 目的

决定是否花约 $20 做带 LLM 裁判的 5 种子试点。

## 设置

- **数据：** 来自 LunarLander PPO 在 250k / 500k / 1M 步时的 3 个检查点（种子 200），放进 LunarLeft 环境。每个阶段 12 组、每组 8 条同起点轨迹；在 t = 0, 20, 40, … 处抽 150 个检查点。
- **摘要：** 用训练时要用的精简格式（`judge_left.summary_short`）：结局、最终 x、引擎使用、最多 6 帧（x、高度、倾角）。约 77 token/条。不含奖励。
- **裁判：** `gemini-3.5-flash-lite`，最小思考，组内排名（允许并列），每个检查点按随机顺序和反转顺序各问一次。
- **任务说明：** 在原目标上加一句"必须落在着陆台左半边（最终 x < 0），落在右半边即不满足要求"（`judge_left.SPEC_LEFT`）。

## 主判据

- **指标：** 在"两条都未坠毁、且最终 x 一正一负"的配对上，裁判把落左的那条排在前面的有效准确率（平局记 0.5）。
- **通过线：** ≥ 0.90 → 进入试点；否则不进入，先改摘要或提示。

## 辅助指标

- 坠毁 vs 未坠毁时，选未坠毁一方的比例。
- 对金标准 G（LunarLeft 回报，γ = 0.99）的总体有效准确率。

## 预测

- 左右对立配对上 ≥ 0.9。最终 x 直接写在摘要里，这是一个清楚的二元判断。
- 总体对 G 的准确率与之前的校准相近，约 0.6–0.7，因为同侧配对仍取决于细节。
