# 目标导向稀疏奖励任务（MiniGrid DoorKey）：事先约定（写于正式运行前，2026-10-27）

## 任务

MiniGrid DoorKey：先捡钥匙、开门，再走到目标。只有到达目标时才有奖励 1 − 0.9·步数/上限，否则为 0。回合长度可变，到达即终止。

- 观测：7×7×3 局部视野展平（147 维）。动作：7 个离散动作。
- 同一 seed 布局相同，因此可以做"同一初始状态的一组"。
- 比较 oracle 与之前一样，比较同一 t 的 reward-to-go。
  - 一组里全都没到达时，全部是平局，没有信号。
  - 已经到达并终止的轨迹，在之后的 t 上不参与比较。

### 环境与步数如何选（只看了 PPO 试跑）

- **规则（试跑前定下）：** 取 PPO 在 1M 步时两个调参种子（100、101）成功率都 ≥ 0.8 的最大地图。
- **试跑结果：**
  - 5×5：两个种子到约 0.2–0.3M 步时成功率都达到 1.0。
  - 6×6：种子 100 成功，种子 101 在 1M 步内成功率始终 ≤ 0.02。
  - 8×8：种子 100 成功，种子 101 始终为 0。
  - 后两者是探索受限的任务，按规则排除。
- **选定：** MiniGrid-DoorKey-5x5-v0。
- **步数：** PPO 在约 0.3M 步时已饱和，所以正式实验取 500k 步，主指标改用学习曲线下面积（AUC，即样本效率）。这两个决定只依据 PPO 试跑，没有看任何比较方法。

## 方法与设置

- 方法：ppo（标量 + critic）、grpo_step（标量，与 pair 同粒度）、pair_step、pcrit_res、rm_ppo、spo。全部默认超参。
- 种子 1–10，结果在 `results/goal`。

## 指标

- **主指标：** AUC，即 500k 步内回报的平均（50 段）。
- **次指标：**
  - 最终成功率：最后 10% 步数内 success_rate 的平均；
  - 最终回报；
  - "失败种子"数：最终成功率 < 0.5 的种子。

## 检验（AUC，Welch t 检验，4 个一起做 Holm 校正）

1. pair_step vs ppo：只用比较，相对用标量 + critic 的代价。
2. pcrit_res vs pair_step。
3. rm_ppo vs pair_step。
4. spo vs pair_step。

辅助报告：grpo_step vs pair_step（与 Phase B 的同粒度对照一致）、最终成功率、Mann-Whitney。

## 判断标准

- **"只用比较在目标导向任务上可用"**：pair_step 或 pcrit_res 的最终成功率均值 ≥ 0.9，且失败种子 ≤ 1。
- 上面 4 个检验校正后显著的，按方向如实报告；不显著的写"无可测差别"。

## 事先写下的预测

- 所有方法都能解 5×5，最终成功率 ≥ 0.9。
- 在第一次成功之前，两条路线都没有信号：比较全是平局，标量全是 0。之后比较的含义就是"谁更早到达"，信息量与标量回报差不多。所以预计 pair_step 的 AUC 与 grpo_step 相近，比 ppo 低一些（ppo 有 critic），但差距在 15% 以内。
- rm_ppo 与 pair_step 相近：奖励只取决于是否成功、何时成功，容易被奖励模型拟合。
- spo 因为回合短、轨迹级信用分配的损失小，表现也不差。
